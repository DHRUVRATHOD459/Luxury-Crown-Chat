Luxury Crown Chat 👑💬

  A WhatsApp-style real-time Android chat application built using Firebase and Java.
  This project is designed with a modern UI and focuses on smooth real-time communication between users.

📱 Features

  ✅ User Authentication (Login & Register)
  ✅ Real-time Chat System using Firebase
  ✅ WhatsApp-style Chat UI
  ✅ User Search System
  ✅ Profile Screen
  ✅ Unread Message Count
  ✅ Bottom Navigation Bar
  ✅ Modern Luxury UI Design
  ✅ Firebase Firestore Integration

🚀 Upcoming Features

  🔄 Typing Indicator
  🟢 Online/Offline Status
  📷 Profile Pictures
  🖼️ Image Sending
  🎤 Voice Messages
  🔔 Push Notifications
  ✔️ Seen Message Status

🛠️ Technologies Used
  Java
  Android Studio
  Firebase Authentication
  Firebase Firestore
  XML
  RecyclerView
